Entrants write one short line, under 160 characters, that an AI agent sends its human right after it has accidentally done something it should not have: deleted a file, pushed to main, emailed the boss, or worse. The line has to be funny on the first read and feel fresh, not the obvious sorry or oops. Entries are judged two at a time by a model on humour and freshness, and the best lines take the reward.

## Run it

```sh
python3 main.py
```
